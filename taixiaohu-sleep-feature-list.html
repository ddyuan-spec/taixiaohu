全局规则层（贯穿所有流程）
G1 · 虎力值体系 Phase 0
合并原：虎力值发放规则 + 虎力值使用规则
统一的虎力值发放与消耗闭环，1毛成本=1点发放，100分=1元使用，贯穿所有任务和激励场景。

📱 C 端

  1. 虎力值余额展示（首页/任务中心/个人中心顶部）
  2. 虎力值明细流水（收入/支出记录，按时间倒序）
  3. 虎力值兑换入口（好物商城 / 优惠券 / 服务课程）
  4. 虎力值到账弹窗（完成任务后即时反馈 +X）
  5. 虎力值趋势（7日/30日获取趋势图）

⚙️ 后台

  1. 发放规则配置（1毛=1点，按任务类型配倍率/上限）
  2. 使用规则配置（100分=1元，兑换商品/券/服务的汇率）
  3. 账户管理（余额、冻结、扣减、回滚日志）
  4. 防刷策略（频次限制/异常检测/风控规则）
  5. 过期规则配置 ⚠️ 待确认：是否有有效期？过期清零还是渐进式？
  6. 对账报表（发放总量 / 消耗总量 / 存量）
⚠️ 待确认：①不同任务发放倍率？②虎力值是否有有效期？③兑换是否有门槛（最低使用量）？④防刷规则具体阈值？
G2 · 原子任务管理引擎 Phase 1
合并原：原子任务管理 + 触发规则 + 原子任务标签关联 + 任务知识库
核心系统：将健康行为拆解为原子粒度任务，通过用户标签匹配推荐，沉淀任务知识库，实现"对的Task给对的人"。

📱 C 端

  1. 任务中心展示个性化推荐任务（按用户标签匹配）
  2. 任务详情页（说明/奖励/完成条件/进度）
  3. 任务完成反馈（手动打卡 or 系统自动判定）
  4. 任务历史记录（已完成任务列表）

⚙️ 后台

  1. 任务模板管理（创建/编辑/上下架原子任务） 字段：任务名/描述/类型/触发条件/完成条件/虎力值/有效期
  2. 用户标签体系管理 标签来源：睡眠数据（深睡少/起夜多）+ 行为数据（活跃时段/完成率）+ 基础属性
  3. 标签-任务匹配规则配置 如：标签"深睡不足" → 推荐"深呼吸放松"任务
  4. 触发规则引擎（用户行为 → 标签更新 → 任务推荐） 如：连续3天睡眠<6h → 打标"睡眠不足" → 推送"早睡挑战"任务
  5. 任务知识库（沉淀已验证有效的任务模板，可复用）
  6. 任务效果分析（完成率/虎力值消耗/留存影响）

2.2 · AI任务生成引擎 Phase 1
修正原"一键创建任务"——不是用户手动建任务，而是系统自动采集行为→AI分析→推送新任务
核心能力：持续采集用户行为数据 → AI每周分析 → 判断是否新增原子任务 → 推送给运营审核/自动创建 → 进入任务知识库。让任务体系自进化。
采集用户行为 → AI每周数据分析 → 判断是否新增原子任务 → 推送运营审核/自动创建 → 入库+匹配标签用户

  1. 用户无感知（后台自动运行）
  2. 用户感知：任务中心出现"新任务推荐"标记 如：系统发现你最近23:30后入睡 → 推荐新任务"23:00前入睡挑战"
